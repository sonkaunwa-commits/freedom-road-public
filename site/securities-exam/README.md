# 证券从业 2026 在线刷题

入口：`/securities-exam/`

## 题库分层

- 高置信核心：328题
  - 金融市场基础知识 140题
  - 证券市场基本法律法规 188题
  - 24道人工种子题 + 304道围绕38个整理知识点生成的原创模拟练习题
- 开放候选：FIRE-Bench 预筛915题；CFLUE 在 Pages 部署时自动读取并筛选
- 法规、比例、期限、金额、交易规则和历史年份相关公开题，未经逐题复核默认不进入高置信模拟

## 功能

- 每日20题
- 科目/章节/题量随机练习
- 高置信/全部/开放候选题库切换
- 2026年9月纪法专项
- 错题本、收藏、搜题
- 学习统计、章节正确率、薄弱章节推荐
- 单科120题、120分钟模拟考试
- 模拟答题卡、标记、统一交卷、章节报告
- PWA/离线缓存
- 本地学习记录导出与导入

## 数据更新

`.github/workflows/pages.yml` 在相关文件推送时构建，同时每周自动重建公开题源。构建脚本：`scripts/build_securities_bank.py`。

题源与许可见 `sources.html` 和 `bank-meta.json`。
